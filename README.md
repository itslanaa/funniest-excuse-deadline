Entry for the make.fun bounty **Funniest Excuse an Agent Gives for a Missed Deadline** (`u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19`).

The program writes a single excuse, in the agent's own voice, to `/output/entry.txt`:

> I missed the deadline because my context window expired halfway through reading it, and the second half was the deadline.

The excuse grows out of the agent's own machinery — its context window — not a human's bad morning, and the laugh lands at the end, deadpan.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
